SEO3 · Developer Analytics Platform

Global Class Diagram

Persisted entities as implemented across the four data-owning microservices — polyglot persistence: developer-service and notification-service and recommendation-service run PostgreSQL / TypeORM, skill-service runs MongoDB / Mongoose. Cross-service links (e.g. a developerId column in another service's database) are soft references only — there is no enforced foreign key across service boundaries, by design of the microservice split.
